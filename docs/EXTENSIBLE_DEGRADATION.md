# 0.0.8：分相接口、CBD、退化及真实CT研究轨

本阶段目标是让微结构、材料、算子与退化机制可组合，并用真实CT来源和守恒检查约束升级。代码可运行、局部残差小或出现容量下降都不等于完成顶刊验收。所有参数和验证范围必须随结果发布。

## 接口与组合

`extensions.Registry`是实例注册表，没有隐式全局插件导入；`ComponentSpec`记录工厂源码hash、schema、假设与单位。`degradation.standard_registry()`提供几何、材料、拓扑、基函数、算子、能量核、SEI、析锂/死锂、损伤、热与求解器入口。调用者可以注册新的工厂；实际模型子块还可以通过`CoupledRecipe.submodel_factories`替换。

| 契约 | 实现与检查 | 不能从接口存在推断的能力 |
|---|---|---|
| 几何provider | `SegmentedCT`、`ArrayGeometry`，明确相标签、轴序、SI尺寸、裁剪与hash | 尚未自动支持所有网格/CT分割算法 |
| 材料catalog | `Phase/PhaseCatalog`，分相固定弹性张量、Mandel化学/热膨胀、电子/离子角色、对角扩散倍率 | 不同宿主化学不能直接混用单一DFN相；非对角扩散需新离散器 |
| 拓扑 | `PorousCBD`或catalog；同一CBD可同时导电子、承载并传输微孔电解液 | 微孔参数不是从CT颜色推断的 |
| 浓度基 | 几何区域、精确体素、力学反应端口区域；连通性、质量/功率配对检查 | 区域BV不能直接套到POD系数；谱/POD已有独立线性模块，接DFN需对应非线性投影 |
| 算子 | 自定义`OperatorBuilder`；同源H/U/S，或标量损伤有理能量核 | 固定H不能无条件用于变化接触或新几何 |
| 退化定律 | `SideLaw`独立拥有reservoir，`ReactionContext`给定状态/电势/温度/面积；`SideContribution`返回电流、库存变化和电位 | 任意用户公式不自动满足质量/耗散，须重新通过数值门禁 |
| 求解与热 | 可替换子模型；当前单体DAE、集总热、零轴向外压 | 有限变形、摩擦、完整三维电芯热场未验证 |

`capabilities.REGIONAL_DFN.require()`明确拒绝缺失能力。框架可以扩展，当前实现不是“几乎所有物理模型均已通过”。同为CBD也可能有黏弹、溶胀、塑性或压力依赖电导；本版仅固定弹性与声明的输运/界面关系。完整非结构网格、FFT、有限变形等可由后端接口接入，但不能列为已验证。

## CBD与真实CT的物理语义

数据来源为[官方电池微结构库](https://www.nlr.gov/transportation/battery-microstructure-library-data)，使用NMC532 1-CAL与石墨5-CAL的三相分割文件。原始下载、SHA256与尺寸记录在外部`data/ct/sources.json`。源文件约4MB，解码约16MB；原体素398nm/126nm。活性形貌来自X射线CT，CBD由数据作者数值重构，不是独立CT分辨的CBD。

源数据将面内1×面内2×厚度作为体积维度，按TIFF逐页第三维的约定显式转换`axes_to_zyx=(1,2,0)`，让DFN厚度轴成为数组最后一维。该轴约定与裁剪都存入provenance；如果新来源定义不同，必须由用户指定，不能自动猜测。

初版只对活性—纯孔隙面施加反应，使CBD包覆颗粒结构失去反应界面。本版允许CBD作为重叠的离子/电子连续体。示例假设CBD微孔率0.47、相对离子效率0.05；孔隙体积包括CBD内部电解液体积，稳态输运对CBD使用相应系数，反应可发生在离子可达的活性—CBD面。**这些是未标定建模参数**，并非本数据测量结果。

小裁剪由固定随机种子、相存在及贯通/可达性条件顺序筛选，保存所有拒绝数量，不按预测容量或应力挑选。无补孔、平滑、强制连桥、相重标或降采样。4³裁剪仅是极小CT来源SVE，用于接口/离散闭环，不具备RVE代表性。

官方数据关联论文：Usseglio-Viretta等，JES165:A3403–A3426（2018），DOI10.1149/2.0731814jes。该工作已研究CBD对输运的影响；当前不是首次将CBD或CT加入DFN。

## 真实变化的界面力学

在活性材料—CBD共享三角面分离两侧节点，对位移跳量施加面积加权的法向/切向线性弹簧。bulk C固定，界面刚度随单元损伤d变化：

`K(d)=Kbulk+κ(d)Kinterface, κ(d)=κres+(1−κres)(1−d)²`。

默认保留κres=1e-3以避免新刚体机制。法向/切向刚度为声明的合成值1e15/5e14Pa/m。每个SVE在每个宏观点拥有一个标量d；不是逐界面裂纹路径、混合模断裂、单边接触闭合或摩擦。

通过对受约束`K(0)`和`Kinterface`的广义谱分解，离线得到

`H(d)=D−Σl FlᵀFl/[1+(κ(d)−1)ρl]`。

在线使用该有理式，不把完好应力乘经验衰减因子。场恢复也使用相同谱分母。能量、应力、µel、温度导数与损伤驱动力Y=−∂dW来自同一函数。每个构建都与d=0及0.63的独立直接FEM求解比较。属于已有Schur补/广义谱思想，不单独宣称原创。

Y驱动有阈值不可逆损伤；同一d还通过明确的现象学关系降低可达反应面积和电子输运。宿主锂库存仍保留，并不凭空删除活性材料。该模型描述接触损失；不能等同于已完整实现颗粒碎裂、材料脱落或拓扑更新后的全部LAM。

当前谱构建限制1800个约束后机械自由度，分配稠密矩阵前检查；细场与在线系数分开缓存。谱维数仍可能随界面复杂度增长，尚未实现大规模界面模态认证压缩。

6³更大CT裁剪发现同一相内仅角/棱相接的片段在拆界面后产生机制，已按相内面连通分量拆分节点，不能用很小正刚度掩盖。其完整变化界面模型仍触发RSS限额，保留失败，较大示例只运行冻结损伤的精确H(d0)分支。冻结分支与同一cohesive模型在固定d处等价，不冒充较大结构已通过全部退化。关闭损伤时预先凝聚常数H还显著降低完整固相参照的编译内存。

## SEI、析锂、剥离、死锂与闭合库存

SEI采用带阴极电位门控的溶剂扩散限制变体，跟踪新增SEI绑定的mol Li/m³；初始膜厚是固定基准。膜厚反馈局部串联电阻，区域总膜电流由独立代数未知量求解，包含主反应与全部副反应。

析锂/剥离采用被动的分段线性支路：负金属锂过电势触发析锂，正过电势与已有金属锂库存触发剥离。SEI依赖的衰减将可逆析出锂转为死锂。该模型不冒充PyBaMM原生非对称BV析锂算法；定律可替换，但要重验耗散及库存。

每个副反应都返回`Σ reservoir_dot = −Aaccessible jside/F`。析锂转死锂的内部转移在两库存间正负抵消。主反应、SEI、析锂总和进入同一DFN电荷/电解液源。可循环宿主/电解液锂减少时，总预算应满足

`Nhost+Nelectrolyte+NSEI+Nplated+Ndead=constant`。

有SEI时，原生不含这些新reservoir的`Total lithium`会减少，这是LLI，不是守恒失败；新的总库存才是权威预算。初始化金属锂按可达面积分配，避免随着区域数增加而重复计库存。金属锂暂存与死锂不可逆损失分别报告；LLI等价Ah不能直接当作端电压窗口内可放出的容量。

输出契约：退化物理状态使用`MORQEX aging ...`命名空间，以及报告/研究脚本合成的全库存。为兼容原生DFN装配仍保留NoSEI/NoPlating脚手架，一些原生SEI/析锂诊断名称仍为零，不能拿这些旧字段代替新模型的库存。全库存、容量与耗散的正式结果均来自上述新状态；完整原生命名兼容适配尚非本版承诺。

每区域检查主/副反应、膜欧姆热、扩散功率恒等式。全局内能含化学自由能原函数、SEI储能和`Fel−T Fel,T`，热方程包括`Y d_dot`及`T Fel,dT d_dot`。孔隙变化导致的电解液混合熵项也显式保留。仍限定理想电解液、固定bulk C、零化学OCV熵、常数热容量与零机械外功；逐工况熵/耗散检查不是普遍离散稳定性定理。

参考：[O’Kane等2022](https://pubs.rsc.org/en/content/articlehtml/2022/cp/d2cp00417h)、[PyBaMM耦合退化示例](https://docs.pybamm.org/en/v25.12.1/source/examples/notebooks/models/coupled-degradation.html)、[Iqbal等2021界面脱粘先例](https://doi.org/10.1016/j.compstruct.2020.113173)。本版没有完整复现这些论文的全部算法或实验。

## 运行范围、失败与误差

CT局部SVE的输运系数不能不加验证地代表整个电极。某石墨裁剪的离子效率仅约0.011：直接用于电极厚度后，高电流导致电解液耗尽。新增可配置的正浓度适用域事件提前拒绝，不以负浓度、裁剪或放松容差掩盖失败。

原始2.5–4.2V协议还会遇到区域浓度先越界：当前使用的凸化OKane2022参数并非NMC532/该石墨CT的校准参数。示例循环在明确的有效电压窗口内完成，不能改名为复现原始全电压容量或寿命。单独的薄电极/低温脉冲是机制激活数值测试，参数改动必须单列。

新增端口区域候选用全阶机械化学势行响应、真实反应面积/体积构造无训练轨迹的连通分区。与几何基按相同模式数、相同完整参照和物理时间比较；若目标不达标，应富集或使用全阶，并明确其成本，不能以增阶所得精度宣称同阶方法创新。当前完整离线响应仍有N≤128资格限制。

必须分别报告：算子离散一致性、浓度截断、局部应力/P99、宏观网格、时间、SVE代表性和材料误差。不同退化模式采用单独/组合对照；同窗口同周期比较可放出Ah与LLI，避免把初始SOC差异当衰减。输出图来自真实数值场，统一色标，显示CT原体积/裁剪大小，不把4³小图称为完整真实电极预测。
