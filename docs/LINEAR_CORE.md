# 0.0.2 线性研究核心：实现、证据和未通过项

2026-11-24，分支 `research/verified-linear-core`。这是固定几何/固定刚度的小变形研究原型；不将版本号视为MORPH-0全部资格通过，也不视为论文验收。原GEMsim的274源码文件保持原迁移hash。

## 实际实现

| 文件 | 输入→输出 | 当前边界 |
|---|---|---|
| `mechanics/tensors.py` | Mandel张量/旋转/完整SPD刚度/能量和C'化学势 | FP64、小应变 |
| `mechanics/mesh.py` | GEM体素→正体积Tet4；相、母体素ID、连通分量、外表面/压力载荷 | 固定共节点粘结拓扑；真孔隙不装配 |
| `mechanics/constraints.py` | KUBC/PBC/Neumann→约束投影与相容刚体零空间 | 周期面需几何匹配；周期切割孤岛的旋转不被误删 |
| `mechanics/reference.py` | 一次装配/分解→多RHS、完整场、反力、原始平衡残差 | 稀疏LU为当前小算例默认；未平衡孤岛载荷拒绝 |
| `mechanics/matrix_free.py` | 元素刚度作用+CG/Jacobi→同一离散解 | 不装全局K；不是无元素矩阵；失败显式返回错误 |
| `transport.py` | 活性体素/颗粒ID/XYZ对角D→守恒FV、真实表面通量和库存 | 无跨颗粒ID扩散；不支持非对角D，明确拒绝 |
| `concentration.py` | 几何/谱/质量POD/联合度量POD→模式、Mr/Kr/Br | 每个扩散分量常数必须在空间内；一般不保证正性 |
| `energy.py` | 同一Tet离散/宏观应变/浓度模式→U/S/H/h/w0、梯度和模式mu | KUBC/PBC，应变控制；参考非零项保留；外部节点载荷不在此响应算子内 |
| `statistics.py` | 同一S→精确均值/协方差、加权P99/CVaR包络 | 非线性主应力先由张量恢复；包络只针对给定域内已存储离散响应 |
| `coupling.py` | 同一能量+模式FV→隐式扩散/力学双向演化及储库BV反应 | 凸二次化学能；尚无DFN的电解液/电荷守恒或端电压 |
| `adaptivity.py` | 力学Galerkin残差Gram→当前输入的富集和精确离散能量误差 | 不覆盖浓度截断；返回模型能量修正，不偷偷改瞬态模型 |
| `macroscale.py` | 多层算子/厚度/共同侧向应变→连续牵引、压力或厚度约束 | 一维层合，不是三维全电芯 |

所有数值/构建/测试在外部workspace运行。算子manifest保存数据校验、几何/材料/基/参考态/边界指纹、实现内容hash、张量顺序及精度。耦合checkpoint核对物理模型hash、库存与能量，错误模型不能继续旧状态。

## 数学关系与离散范围

应力/应变Mandel顺序为 `[xx,yy,zz,sqrt(2)yz,sqrt(2)xz,sqrt(2)xy]`。完整RVE体积V归一；孔隙贡献零能量但不缩小V。`c=cref+Phi a`，a为mol/m³，Phi无量纲。化学膨胀是相对于cref的增量。

给定线性模式时，离线精确响应满足 `W(q)=qᵀHq/2+hᵀq+w0`；`q=[E_M,a]`。宏观应力为应变导数，模式机械势系数为 `Mr⁻¹ ∂W/∂a`，不能直接把模式导数当局部势。Level A仅访问低维H；精确矩仅访问离线Gram；ROI/全场恢复才访问对应U/S。

当前耦合使用 `F=W+κ aᵀMr a/2`，`Mr adot+Lr mur=Br j`，其中 `mur=Mr⁻¹ ∂F/∂a`、`Lr=Kr/κ`。κ单位J m³/mol²；因此无力学且全空间时严格退化为已独立验证的FV Fick扩散。储库反应 `j=2j0 sinh((mu_bath-PhiΓ mur)/(2RT))`，j>0进入固体；电流为F乘总进入摩尔速率。它是单储库边界构件，不能称完整电池Butler–Volmer/DFN模型。

后向Euler对二次F有离散恒等式：

`Fnew-Fold-Wmech-dt(Pchem-Ddiff-Dreaction)+ΔaᵀHtotalΔa/2=0`。

外部宏观应变改变的功在旧化学状态上单独计算。封闭无功时F下降；储库供能时允许F升高。默认充分可行性检查为 `sum_k ||phi_k||∞ |a_k| <= min(cref,cmax-cref)`，在线不恢复体场，但可保守拒绝实际可行状态；精确检查是显式O(Nm)选项。未做随意裁剪。

机械残差证书离线计算 `RᵀKr⁻¹R/V`，包括非零参考列，在线求二次型。其值精确等于给定浓度模式内的离散位移能量范数平方；Galerkin势能误差是其一半。它不能证明参考连续体误差、浓度截断误差、P99或点态极值误差。

## 独立验证证据

当前自身测试 **53通过**；原GEMsim迁移测试的历史结果7通过/9可选后端跳过（本次未改原迁移代码，不把跳过记通过）。新测试包括：完整各向异性6载荷patch、独立层合解析、Neumann压力功/非平衡拒绝、真空孤岛及周期切割孤岛、制造解收敛、C'项有限差分、精确响应与重新求解、H/混合导数/模式质量、机械残差恒等式、体积尾部区间、扩散解析特征模/库存、全谱退化、力学反馈、储库反应外功、层合约束和断点重启。

球形独立解析采用指定 `c=c0+Δc(r/R)²`，无牵引，固定各向同性E/ν/β。自由球解析位移/径向及环向应力与弹性能直接代入检查；不从ROM生成参照。拟合球网格最新n=24为4368节点、25967Tet，位移误差0.0650%、应力全域L2约11.01%、固定内域7.47%、能量1.331%、体积0.501%，残差1.07e-13。**小残差没有消除空间/几何误差；全域应力10%目标仍未通过。**

先前n=28探测6794节点/41412Tet获得应力9.60%、位移0.0476%、能量0.954%，但采样峰值约1476MiB，靠近1536MiB门槛。该历史记录保留；当前具有逐文件源码hash的可重复默认资格止于n=24，不据n=28单例宣称所有几何收敛。体素球阶梯边界误差另列，不能只截去边界就声称全域准确。

## 三个独立GEMsim结构的失败记录

配置见 `configs/linear_study.toml`；种子104/205/306，每例5³体素、80个活性体素；训练与验证载荷随机种子不同，验证具有更高空间频率。物性是合成验证值，不用于材料结论。每个结构单独建基，未宣称跨拓扑转移。全FV坐标加同一Tet完整静态凝聚为离散参照，另做独立FEM重求解校验，误差约4e-16。

下表是最多6个非恒定模式（总阶7/8）下的留出应力L2误差：

|---|---:|---:|---:|---:|
| 104 | 76.75% | 66.71% | 72.54% | 72.57% |
| 205 | 51.07% | 48.16% | 56.90% | 57.13% |

联合POD未展示稳定优势，C1创新假设未通过。保留这些载荷，不通过改训练/减弱验证来隐藏失败。谱基扫描到64/65阶时仍有6.43%–22.61%应力误差，当前扫描仅全80阶达到5%门槛。该扫描依赖离线真值，是资格分析，**不是在线误差估计器**。这说明任意初始场没有低秩保证，下一步应比较反应通量可达子空间、局部谱/图分解和目标受限模式，而非默认普通加权POD就是最终方法。

P99包络在4/16/64代表单元时覆盖真值，但64点区间宽度仍为真P99的约18倍，C2的低成本可靠预测未通过。全离散响应代表集给零宽度区间，但失去采样收益。不能用“覆盖率100%”掩盖区间没有实用辨识力。

闭系统20步双向试验的能量平衡绝对残差不超过约1.4e-11 J/m³，锂库存达到打印精度守恒；储库试验残差约1.5e-14 J/m³。它们证明该二次微结构构件的离散关系，不证明真实电池、非凸化学自由能、非线性输运或DFN全耦合正确。时间离散精度和长期工况仍需研究。

## 性能解释

同一5³结构、同输入浓度模式、FP64/单核、复用LU、同样返回位移/应变/应力/能量，当前完整场响应重构约为参考重求解的 **2.2–2.4倍**。计时双方均不含反力/残差输出，另行检查平衡。算子构建、训练和模式误差另计；低维模式精度未过，不能将这个微基准倍率当论文合格加速。宏观输出对完整场求解的比值另标输出不同。

4³/8³、相刚度对比1/100的同Tet比较中，CG/Jacobi解与LU应力差<1e-9，但小规模在线明显更慢；8³的元素刚度存储略小于K+LU数据存储，统计不含共同B/D/C或临时数组，不能称峰值内存。结论只支持当前小规模默认LU，不能排除AMG/FFT在更大规模有优势。
