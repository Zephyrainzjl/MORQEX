# 有状态微结构—DFN双向端口（0.0.7）

这是已实现的研究原型及其适用范围，不是期刊验收声明。源文件在`src/morqex/electrochemistry/microstructure_*.py`；数值、缓存、HTML、构建和检查点均在外部`morph_workspace`。

## 1. 映射需要历史状态

宏观位置X上的未知量包括电解液浓度、电解液/固相电势、温度，以及微结构区域浓度a(X,t)。这些a**替换**原DFN径向颗粒状态，不另添一份锂库存。单一平均SOC不能唯一决定复杂微结构场。

设细胞体积矩阵W，互不相交且连通的区域指示基P，Wr=PᵀWP，R=Wr⁻¹PᵀW。有

`c=Pa, a=Rc, RP=I, w_rᵀR=wᵀ`。

PR一般是投影，不是恒等；从平均SOC恢复任意真实场不可能。化学势的对偶投影为Wr⁻¹PᵀWµ，这使浓度变化与化学势的功率配对保持一致。P为非负分片常数，物理范围由状态事件检查，不通过裁剪伪造守恒。

每次整体DAE求解同时更新：

1. DFN提供局部Δφ、ce和集总T，层合力学提供宏观轴向应变E。
2. 微结构图输运与实际可达活性界面BV更新a。
3. 同一FEM能量算子提供µel、平均应力和耦合导数；区域反应总和返回DFN电荷/电解液方程。
4. 按需以P、U、S恢复浓度、位移和应力；宏观与精确分量二阶矩查询不加载细场。

这是单体式隐式耦合，不是外部SOC到应力的后处理表。`MicrostructureDFNRuntime.advance(dt,I)`在热/力/电化学状态上继续积分，支持变流、静置、数值检查点和嵌套富集。报告中滑块重放已求得轨迹；改变电流重新演算需运行Python，HTML不冒充浏览器内DFN。

## 2. 同一能量与反应端口

固定几何、固定线弹性C、各向同性线性化学/热膨胀下，离线凝聚得到每RVE体积能量

`W(E,a,T)=1/2 qᵀHq, q=[E,a−a_ref,T−T_ref]`。

`σ̄xx=∂E W, µel=Wr⁻¹∂a W`。H对称、半正定（容许自由膨胀零能方向）；U/S来自同一批受约束Tet4求解。宏观横向为平面应变，轴向通过电极/隔膜层合平衡，采用零外压或固定总厚度，外部机械功为零。不是完整三维电芯壳体。

区域化学势`µr=−F U(ar/cmax,T)+λµel,r`；λ=0为单向对照，λ=1为双向。正曲率化学下，边通量取`Jrs=grs Dmid (µr−µs)/f''secant`，反对称装配。实际可达面积ar给出`wr a_dot_r=−Σs Jrs−ar jr/F`。界面`ηr=Δφ−Ur+λµel,r/F`，`jr=2j0,r sinh(Fηr/(2RT))`。

由此局部离散恒等式为

`Σr wr a_dot_r µr + Σedges Jrs(µr−µs) + Σr ar jr ηr − Δφ Σr ar jr = 0`。

扩散/对称BV两项非负。Σar jr就是DFN使用的体积反应电流；不能重复加入OCV的力学修正。热反馈需要自由能对T的导数，不把W直接等同内能。

## 3. 热、内能与熵核验

当前限定：理想电解液（热力学因子1）、常数迁移数、零化学OCV熵系数、常数密度/Cp、固定C、无外部机械功。违背这些前提时拒绝沿用当前能量闭合。

电输入功率Pin=−IV，Pport=电极积分Δφ jv，Qmacro=Pin−Pport。Qmacro包含电解液混合自由能变化，不能单独称为纯欧姆耗散。微观扩散/界面耗散来自上式。热方程使用这些功率及`T Σ wr µel,T a_dot`，有效热容含`−λT Fel,TT`，热体积为实际Cell volume。

独立从浓度重算`Fchem=Σwr∫−FU(c/cmax)dc`（含固定PyBaMM端点渐近项），从FEM算子重算Fel，得到

`U=Cp V(T−T0)+Fchem+λ(Fel−T Fel,T)`。

与时间积分的外电功/换热比较，不再仅检查温度ODE账本。理想电解液混合内能为零，熵中仍需包含混合熵。总熵为热熵、弹性熵和电解液混合熵之和，与积分D/T、Qcool/T比较。

宏观总耗散还扣除电解液混合自由能的浓度导数项。原生电解液FV采用grad(c)/c离散；本版本逐工况检查总耗散非负及熵账本，**尚无对所有网格、浓度和步长成立的离散熵稳定性定理**。不是完整孔隙电解液三维参照。

## 4. 不依赖细网格规模的局部BV闭合上界

在同一代表状态c=Pa上，细力学化学势与区域均值差为`δµi=Di q`。区域内c、j0、化学U相同，力学µ不同。离线储存

`Gr=Σi∈r Ai DiᵀDi, br,k=maxi∈r |Di,k|`。

MVT与Cauchy给出区域总反应电流差的绝对上界

`Br=λ j0,r/(RT) cosh(|Fηr/(2RT)|+λ br·|q|/(2RT)) sqrt(ar qᵀGr q)`。

因此`|jv,fine(Pa)−jv,regional(a)| ≤ ΣBr`。使用真实可达表面积权重，零面积区域贡献零；实现包含保守浮点二次型舍入裕量。在线复杂度O(r(r+2)²)，无需P、细网格或FEM。以1C名义体积电流归一化可避免静置时除零。

这是**同一代表浓度处的瞬时力学反应闭合上界**，不覆盖浓度截断误差、非线性轨迹、连续体误差或最大点应力。按需细FV缺陷指示器另作经验指标，成本随N增长；不混称严格全程证书。MVT/Cauchy、区域投影、响应预计算都是成熟工具，组合的效用和差异还需先进基线验证。

## 5. 状态连续富集

嵌套Pnew满足`Pnew Rnew Pold=Pold`，用`anew=Rnew Pold aold`，保持代表浓度、库存、化学自由能和弹性能不变，其他微分状态原样移交。热弹性熵也连续。新的代数电势须重求一致初值，端电压允许由改进闭合产生代数跳变。拒绝非嵌套有损转移及不同材料/几何算子。

检查点是数值NPZ+SHA256、参数/模型/状态布局指纹，不使用pickle。编译、恢复、富集和冷查询成本单列；毫秒级暖步进是实测软实时能力，没有硬实时期限保证。

## 6. 微结构及参数范围

直接调用集成GEMsim随机场。体素活性固相图和孔隙图均须贯通；只在连接至相应边界的孔隙—活性面施加反应。绝缘孔隙保持零刚度。面不连通固体的角/棱接触不绑定共节点；孤岛刚体由参考FEM处理。电极和电解液有效系数分别从同一几何的稳态TPFA算出，不任意重标体积分数。

当前为合成、低分辨率SVE，不证明RVE代表性。12³生产路径从4³标签精确复制细化，N=1134，验证离线构建和低维在线运行，不代表1134状态三维参照准确性已经验证。空间细化与独立结构种子不可混称。

材料轨为显式修改的OKane2022：凸化化学OCP（负极最大改动约21.43mV）、Ω×0.1、合成热膨胀/隔膜刚度。为控制编译内存，4001点OCP表自适应压缩至454/137节点，分段多项式极值核对电压误差≤20µV、严格正曲率；斜率相对差在审计网格≤5%。全阶和降阶使用完全相同表和求解容差。这不是原参数完整复现或材料机制结论。

## 7. 对照与可检验研究假设

已有POD/FE²、结构保持端口降阶、NTFA/EHM、微结构—DFN参数桥接均是直接先例。Tu等2026的VCH/POD离子输运降阶已给出微尺度ODE闭合；Tredenick等2025已比较CT解析与DFN。Zhao等2026的SPMe降阶结合球形扩散应力、集总热和厚度，并已有实验验证，不能仅凭加入热/应力宣称创新。

待验证C类问题：能量与反应功率对偶的非均匀真实几何DFN闭合，局部非线性反应误差的r维可计算上界，以及保持状态/能量的按需微结构富集是否共同改善可观测局部力学量的成本。不存在已确立D类“首次”贡献。

对照包括每活性体素一个状态的完整固相微结构模型、每连通分量均匀浓度、几何区域、力学探针辅助区域、去力反馈、倍率、约束、宏观网格、独立结构和完整循环。相同物理时间比较场与曲线；分别报告截断、宏观离散、参数和代表性限制。未与完整孔隙三维电化学/先进NTFA/EHM复现比较前，不称顶刊完整验证。
