# 稀疏耦合与按模式构建的跨尺度算子（0.0.5）

2026-11-24。分支 `research/sparse-coupled-scaling`。这是固定二次自由能/线弹性框架的规模升级；不是完整DFN、工业规模、真实CT/材料设计或已通过期刊审稿。0.0.4的小系统稠密认证保持原接口/限制，作为交叉基线，不直接放开N≤512。

## 方法出处与本轮问题

Schur消元、混合块求解、GMRES、合理预条件和有理Krylov均为已有方法。pH投影沿用R26，输入响应空间沿用R25等谱系；完整耦合响应构造是领域内适配，尚不认定原创。参考[原始SciPy GMRES接口](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.gmres.html)核对真实残差与左预条件的含义；[NGSolve静态凝聚教程](https://docu.ngsolve.org/latest/i-tutorials/unit-1.4-staticcond/staticcond.html)解释一般Schur代数，本文并非使用其单元内部自由度消元算法。没有把借鉴的代数重新命名为新贡献。

上轮必须构造完整浓度H，并对每个活性体素构造应力响应列；前者O(N²)，后者O(N_elem N)。实际只有80个活性体素。新路径不构造这两类全体素响应：完整参考保持稀疏机械/化学变量；低维路径只计算实际保留的m个浓度模式，宏观在线核与几何/全域基分开存储。

## 1. 稀疏自由能与两条完整参考

固定C、零化学参考应变、KUBC/PBC。设T将活性体素浓度c映射至各单元Mandel化学应变，D为应变-位移矩阵，P为既有刚体模态处理后的约束投影，V_Y为完整RVE体积。

K_r=PᵀDᵀWC DP，F=PᵀDᵀWC T，D_ch=TᵀWC T/V_Y。

每个单元对应单个母体素，因此D_ch为对角；空隙从固体网格排除，不能用软材料替代。本轮逐母体素核对力学积分体积与FV库存，不按数组长度硬接不同几何。完整各向异性Mandel C和逐单元各向异性膨胀均可输入；输运仍仅对角XYZ扩散，沿用原能力限制。

令z=sqrt(κM)c；用机械对角缩放后的波动坐标v，使机械块K_m对角为1；定义稀疏J、对角D_z、机械宏观R与化学宏观G₀，使能量密度为

F(v,z,E)=½vᵀK_m v−vᵀJz+½zᵀD_z z+vᵀRE+zᵀG₀E+½EᵀK_EE。

消元得H_z=D_z−JᵀK_m⁻¹J，G=G₀+JᵀK_m⁻¹R，且I≤H_z≤D_z。H_z仅通过机械求解作用于向量/少量模式，不形成N×N矩阵。L=M⁻½K_diff M⁻½为稀疏对称半正定Fick算子。

引入归一化化学势p，完整BE可写为：

```
[ K_m   -J     0    ] [v]   [ -R E                 ]
[ -Jᵀ   D_z   -I    ] [z] = [ -G₀ E                ]
[  0     I    dt L  ] [p]   [ z_old + dt b u        ]
```

一条参考复用此稀疏混合块LU。另一条对(I+dt L H_z)使用矩阵自由Schur-GMRES，并以(I+dt L D_z)稀疏分解预条件，原机械LU复用。两条每个结构都执行整轨迹交叉，而非选择低效重新装配基线；使用其中在线更快者计算倍率。分解和装配成本分别记录，不能忽略稀疏LU的三维填充。此处“矩阵自由”仅指浓度Schur算子，不表示整个力学矩阵/因子未装配。

完整参考直接使用已求机械坐标核算能量；宏观载荷变化时，旧场在新E下的机械坐标由线性宏观提升更新，不额外重解无必要的旧场。外功、扩散耗散、BE数值耗散和逐连通分量库存均核对。输入端口为已声明摩尔通量，不是电解液/BV/DFN。

## 2. 逐模式构建与质量保持

给定M正交浓度空间V，V_z=sqrt(κM)V，逐列计算H_z V_z；仅保留O(Nm)基/响应列和O(m²)能量矩阵，不存完整位移/应变/应力算子。能量投影W=H_z V_z(V_zᵀH_z V_z)⁻¹，以WᵀLW和Wᵀb生成低维耗散与通量。每个连通分量保留H_z⁻¹ sqrt(M)χ/sqrt(κ)对应的浓度质量Riesz方向。通过有预条件的H_z-CG得到该方向，并核对真实残差；没有用大N稠密求逆。

同时显式加入H_z⁻¹G的宏观化学势提升方向，保证声明宏观应变产生的仿射化学势进入试探/检验空间。新增方向全部计入总阶/离线查询，不能只报原16/32/48阶。消融包括省略质量Riesz的拒绝反例和宏观提升精确包含检查。

比较两类浓度基：原固定Fick边界响应；完整耦合生成元(sI+L H_z)⁻¹b的有理响应及高阶矩。后者通过四个移位稀疏混合块和60个RHS构造，共享完整库费用在每个候选的离线成本中均计入；不读取验证浓度/应力建基。相同结构下的全部已声明端口均可用于离线，包括中途激活热点，因此本轮检验新时间波形，**不是未知端口/几何零样本外推**。

## 3. 不依赖密集H的保守误差界

误差在固定全阶离散生成元下满足

(I+dt L H_z)e_n=e_old−r_n。

由于在H_z范数下此BE映射不扩张，且H_z≤D_z，故

δ_n ≤ δ_old + sqrt(r_nᵀD_z r_n)。

离线对残差列[V_z,L H_z V_z,−b,L G]作D_z加权QR，在线残差系数仅随m/端口数增长。非零初始误差用同一上界包住；累计误差不清零。此界比保留误差动力学可能更保守，但无需完整谱空间、H或强制性下界。原定容限sqrt(0.1)×2保持不变；超限由生产step拒绝，分析trial轨迹单独标记，不计算其合格加速。

H_z≥I还提供物理浓度误差包络；不会以裁剪浓度制造守恒。覆盖范围仍是相同网格/步长/固定线性全阶问题。FP64裕量和数值覆盖测试不是定向舍入证明，也不涵盖空间/时间离散、DFN、材料参数或代表性误差。

## 4. 真正分离在线核、统计和局部场

`StreamedEnergyROM.detach_online()`返回只含小矩阵/缩放常数的`OnlineEnergyKernel`。不保留几何、求解器、N×m浓度基或H作用列；可外置保存、清空源码路径后安装加载并断点恢复。状态只读、模型指纹绑定，保存/恢复核验实现/数组hash与能量/库存。

Level A：能量、宏观应力、模式力及误差证书不访问微网格。批量宏观查询共享一份算子，测试1/100/1000/10000个位置。该测试尚不是多点全电芯动力学。

Level B：精确线性应力均值、分量方差和von Mises平方均值可由小矩阵计算，`detach_statistics()`不携带局部场或体积数组。它们以明确的选区体积归一；完整固体均值与按RVE体积归一的宏观应力相差固相体积分数，不混用。

Level C：`StressLocalization`按显式单元选区逐模式构建应力列，预算在分配前检查；局部恢复成本O(N_requested m)，完整场不免费。本轮不重复存U/E，先提供应力层。P99/最大主应力仍从恢复场计算，绝不当成固定二次型。局部模式按独立FEM同输入交叉，宏观导数与恢复场体积平均一致；对完整耦合参考的末时刻应力/P99误差另报。

## 5. 规模、性能与失败

配置 `configs/sparse_scaling.toml`：8³/14³/18³，三个种子104/205/306，各40步。每个尺寸生成新随机几何，固定物理盒但相关长度按体素给定，故此扫描只检验离散规模适应性；不能当同一微结构的网格收敛或RVE收敛。

本轮无GPU、单逻辑CPU、nice15、AS3GiB/组RSS1.5GiB、180s/CPU120s。8/14³按三种子任务运行；18³合并任务在第三种子触发组RSS限制，已保存失败日志。之后按单结构独立进程重跑并在更换dt时释放旧LU，不提高限额。首次失败数据不纳入最终公平测速，但不删除。

Profiling先例存外部 `sparse_profile`：小规模试探中稀疏因子分解是主要计算项，非GPU/神经网络问题。采用单结构进程隔离控制连续任务内存驻留，不修改其他训练或全局GPU。

最终九结构/54候选及所选模式、覆盖、守恒、误差、离线成本、盈亏平衡、局部场和批量查询，以源码hash一致的 `sparse_scaling.json` 与HTML为准。失败的低阶/Fick候选完整保留。在线倍率包含ROM证书、能量与逐分量库存，输出需求一致；离线和局部场成本单列。估算identity全响应存储仅用公式标记，不称实测内存。

不能将本轮结果升级为全部顶刊验收：球参考全域空间误差、真实CT/材料参数、DFN电荷/电解液/电压、先进NTFA/EHM/近DFN方法复现、非线性与独立原创仍有缺口。稀疏LU填充限制更大网格，后续需公平比较AMG/Hex/FFT或分域方法；不得直接扩大到百万体素并依赖硬限额终止。

最终冻结规模结果：最大N4082、力学自由度13623–13821、56总浓度模式；三独立种子包含误差证书的在线加速119.6–126.7倍（相对两种复用全阶中最快者），末时刻应力场L2误差0.0216%–0.0255%，末时刻P99误差（分母下限1000Pa）0.0093%–0.0768%。完整离线库计费后盈亏平衡14.7–18.4条40步轨迹；完整场恢复另测，不混入在线倍率。当前最高成功任务采样组RSS1262.5MiB，GPU未使用；失败合并任务及控制器终止原因仍保留。全套111测试通过，包括周期全各向异性/剪切膨胀、稀疏双参考、独立紧凑核/重启和余项界。数字只适用于此固定离散二次协议，不代表连续体、真实电芯或期刊验收。

参数范围限制：本轮规模测速的活性相E=1GPa、β=(1,0.6,1.4)×10⁻⁶ m³/mol、κ=0.1，夹持能量给出的最大D_z−1为0.06256。规模加速证据属于此耦合强度与刚度对比范围；小测试β=10⁻⁵覆盖更强能量耦合的正确性，但不能替代大N强耦合/高对比性能验证。该扫描是下一阶段必需项，不能将当前119–127倍推广到任意真实材料。

复杂度边界：在线核按固定m/端口数/扩散分量数讨论与N解耦；分量库存至少需要每个独立扩散分量一个守恒方向，m不能与颗粒数无条件无关。本轮随机相场分量较少，不能外推到大量互不连通颗粒。静态核数组字节数不含小型LU缓存、状态或Python对象；整任务内存看RSS。

## 独立部署入口

完成五个规模任务和汇总后，以下代码只需安装后的morqex和外部紧凑核，不读源码、浓度基或机械求解器：

```python
import json
from pathlib import Path
from morqex.streamed_rom import OnlineEnergyKernel

ws = Path('/home/zephyrain/lw/morph_workspace')
run = json.loads((ws/'reports/sparse_scaling_latest.json').read_text())
data = json.loads((Path(run['run'])/'sparse_scaling.json').read_text())
case = next(c for c in data['cases'] if c['size'] == 18 and c['seed'] == 306)
kernel, state = OnlineEnergyKernel.load(case['compact_kernel_path'])
mean_stress_pa = kernel.macro_stress(state)
```

安装探测清空PYTHONPATH并实际读取此N=4082、56模式核，核对完整场选区平均乘固相分数后与宏观梯度一致。该部署只恢复相应已验证模型的状态和输出，不赋予新几何/新物理适用性。

缩放定义补充：D_k=diag(K_r)，S=D_k⁻¹ᐟ²，T_c=diag(sqrt(κw))，v=D_k¹ᐟ²u_fluct/sqrt(V_Y)。于是K_m=S K_r S，J=S F T_c⁻¹/sqrt(V_Y)，D_z=I+T_c⁻¹D_ch T_c⁻¹。这里F为上文机械化学载荷矩阵，能量函数亦记F仅为常用符号；实现分别为稀疏force和energy。p=T_c⁻¹∂F/∂c=sqrt(M/κ)μ，故扩散动力学是ż=−L p+b u，b=sqrt(κ)M⁻¹ᐟ²BΓP_flux；这些归一化不改变原来的摩尔库存、化学势或RVE能量。
